# AURYN — MVP funcional

Este pacote é uma versão inicial funcional do aplicativo AURYN para organização financeira.

## Recursos
- Dashboard de patrimônio
- Receitas e despesas
- Contas/movimentos
- Carteira de investimentos
- Metas financeiras
- Relatórios por categoria
- Persistência local no navegador (localStorage)
- Layout responsivo para celular e computador
- PWA básico

## Como usar
Abra `index.html` no navegador.

## Próxima etapa para produção
Para transformar este MVP em um produto comercial, é necessário adicionar backend, autenticação, banco de dados, criptografia, recuperação de senha, auditoria, APIs/Open Finance, integrações de investimentos, notificações, permissões e infraestrutura de produção.
